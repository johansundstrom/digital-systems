## Program

Definitions
* Source Code - A computer program written by humans in a preferred language
* Object Code - Output from a compiler
* Compiler - Translator from Source Code to Object Code
* Library - Collection of software resources that can be linked to Source Code
* Linker - Computer program with the purpose of making one (or more) Object Code out of Source Codes and Librarys
* Compiler/Linker - Computer program with purpose of compiling and linking 
* Firmware - A Computer Code kept in a Non Volatile Memory
